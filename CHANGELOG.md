## [6.0.0] - 2026-07-23

### Added

- Group-safe train/dev/sealed dataset manifests with content hashes.
- Metrica synchronized tracking receiver-choice dataset and cross-game ranker.
- Multi-horizon sealed release validation with BA, AUC, Brier, ECE, and non-finite gates.
- Content-addressed frozen release manifest and repeatable acceptance scripts.
- Memory provenance service, matched-seed counterfactual evaluation, and transactional meta-learning.

### Changed

- World model upgraded to v6 with a bounded completion residual around the physics prior.
- Receiver tracking prior influences candidate utility only; completion remains physics plus v6 residual.
- Core runtime configuration now uses one immutable environment snapshot boundary.
- Public integration is consolidated under `src.app`, `src.cli`, and `gfs.py`.

### Fixed

- Completion sealed balanced accuracy improved from 0.500 to 0.581 while preserving prior AUC.
- Runtime and training now treat non-finite pass priors consistently as an unknown 0.5 prior.
- Non-finite multi-step world-model rollout count reduced to zero.
- Failed model branches are disabled independently by checkpoint release gates.
