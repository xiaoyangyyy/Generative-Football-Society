# Release Checklist

Run these checks before staging or pushing:

    python scripts/audit_release_boundary.py
    python scripts/verify_strict_mirror_v99.py
    python -m pytest -q

## Repository Boundary

- Provider raw tracking and event dumps are local inputs and must not be committed.
- Large derived CSV files are regenerated by the dataset builders.
- Acceptance JSON files are canonical machine evidence.
- Checkpoints, smoke reports, caches, and general runtime reports remain ignored.
- No candidate file may exceed 95 MiB.
- Production remains v7.0.0 until an explicit promotion changes data/releases/current.json.

Before push, inspect the exact staged set with:

    git diff --cached --stat
    git status --short
