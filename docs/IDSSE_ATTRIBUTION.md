# IDSSE / Sportec data attribution

The data subset identified by `data/evaluation/data_release_manifest_v1.json`
is adapted from the dataset accompanying:

Manuel Bassek, Robert Rein, Hendrik Weber, and Daniel Memmert (2025),
“An integrated dataset of spatiotemporal and event data in elite soccer,”
*Scientific Data* 12, 195. DOI: https://doi.org/10.1038/s41597-025-04505-y

Data owner and authorizing organization: Deutsche Fußball Liga (DFL). The
official publication states that the dataset was released with DFL
authorization under the Creative Commons Attribution 4.0 International
license: https://creativecommons.org/licenses/by/4.0/

Source dataset: https://doi.org/10.6084/m9.figshare.28196177

Changes made by GFS: the source XML event, tracking, and match-information
files were parsed, synchronized by their published identifiers, sampled or
projected into numeric arrays, and transformed into action, pressure, and pass
triplet representations. These are derived research artifacts, not the
original XML distribution. No match video is included.

No endorsement by DFL, Sportec Solutions, or the dataset authors is implied.
All other external providers are excluded from this licensed supplement.
